1. Official member list from sansad.in

One click per house. Our server reads the public member list that sansad.in itself uses (current, sitting members only: name, party, seat, state — no phone numbers or addresses) and updates the database. Safe to repeat any time: it matches the same people again and only changes what changed.

Photo, party, seat, terms and minister post come with the main load. Attendance takes about half a minute. Positions held (e.g. “Elected to 18th Lok Sabha · June 2024”, committees) needs one request per member, politely spaced, so it takes about 10 minutes per house — you can stop it and continue later.

    Backup: paste or upload the list manually

    Use this only if the one-click load ever stops working. Open the list on sansad.in, select all, copy, paste here.
